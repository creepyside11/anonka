# anonka

Простой Telegram-бот для получения анонимных сообщений.

## Возможности

- персональная ссылка для каждого пользователя;
- отправка текста, фото, видео, голосовых и файлов через копирование сообщения без данных отправителя;
- SQLite для пользователей и текущего получателя сообщения;
- токен бота берётся из переменной окружения `BOT_TOKEN`;
- `/cancel` отменяет текущую отправку.

> Анонимность действует для получателя сообщения: Telegram ID отправителей обрабатывается ботом для маршрутизации сообщений.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="123456:ABCDEF"
python bot.py
```

По умолчанию база создаётся в `bot.db`. При необходимости путь можно изменить через `DB_PATH`.

## Команды

- `/start` — зарегистрироваться и получить свою ссылку;
- `/link` — показать персональную ссылку;
- `/cancel` — отменить отправку анонимного сообщения.
